## 3. Sprint 1 Retrospective (Process Evaluation)

### What Went Well:
*   **Stable Development Velocity:** The team completed all 18 planned story points at a steady, reliable pace without chaotic last-minute changes.
*   **Clean Repository Layout:** The project directory structure remained highly organized, making it easy to manage document merges.
*   **Excellent UI Styling:** The Product Owner gave highly positive feedback regarding Najma's clean frontend layout design.

### What Hindered Progress (Challenges):
*   **Schema Adjustments:** Early relational database changes slowed down backend route configurations slightly mid-sprint.
*   **Sync Time Limits:** Fitting detailed architectural discussions inside our short standing meeting times proved difficult.

### Continuous Improvements for Sprint 2:
1.  **Freeze Requirements Early:** Freeze all academic fields with Sarah during the planning phase before coding begins to prevent database reworks.
2.  **Granular Task Splitting:** Use Trello cards to break large 5-point stories down into smaller daily micro-tasks right from day one.
3.  **Active Blocker Tracking:** Use our WhatsApp channel immediately if a data path variable mismatch occurs to keep velocity high.
