## 📋 Task Breakdown by Feature

### US-15: Real-time Attendance Percentages & US-16: Grade Ingestion Form Elements
- Connect attendance records to display a real-time running metric for students.
- Build input fields for teachers to record numerical scores for midterms and final exams.
- Ensure only assigned course instructors can write or modify data fields inside these logs.

### US-17: Dynamic GPA & Grade Breakdown Layout & US-18: Outstanding Semester Tuition Fee Logs
- Write backend mathematical functions to calculate weighted scores instantly into dynamic GPA metrics.
- Format student record panels to show simple visual grade item lists.
- Build ledger screens tracking total billing amounts, recorded payments, and outstanding balances.

### US-19: Downloadable PDF Fee Receipts & US-20: Automated System Notification Alerts
- Integrate document styling libraries to compile account parameters into neat, downloadable PDF files.
- Add system actions that generate account transaction logs as paperless confirmation sheets.
- Program simple notifications to alert users when grades or schedule attributes update.
