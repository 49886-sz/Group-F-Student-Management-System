## 📋 Task Breakdown by Feature

### US-09: Course Catalog Offerings & US-10: Available Course List View
- Build administrative dashboards to create, edit, or remove course details from database arrays.
- Design responsive layout grids displaying available course names, timetables, and teacher information.
- Write query parameters to dynamically filter course lists by department or semester term.

### US-11: Online Course Registration Matrix & US-12: Maximum Enrollment Seating Limits
- Configure core backend transactional scripts processing user seat reservation submissions.
- Implement conditional logical constraints checking current course capacity before saving new entries.
- Throw a clear user interface error flag warning if a user attempts registration on a fully occupied seat cap.

### US-13: Drop Course Deadlines & US-14: Daily Classroom Attendance Sheets
- Build verification logic monitoring dates to allow course deletion requests within institutional boundaries.
- Design real-time toggle checklists matching class profiles for fast daily teacher attendance data entries.
- Wire database schema pipelines calculating attendance logs into total percentage summaries.
